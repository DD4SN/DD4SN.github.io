# Board skill icons

Board skill icons and board UI images in this directory were obtained from a locally saved Holodori board optimizer page. The page references game AssetBundle images served through the Holodori asset CDN (`cdn.holodori.dev`).

Reference page: `https://holodori.best/tools/board-optimizer`

The CDN exposes game AssetBundle images. The upstream repositories and CDN do not currently provide a redistribution license, so usage rights must be confirmed before a public release.
