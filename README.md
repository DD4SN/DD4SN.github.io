# 홀로도리 계산기

홀로도리의 라이브 편성·점수 분석과 카드, 보드, 악곡 정보를 확인할 수 있는 비공식 웹 도구입니다.

## 서비스

[홀로도리 계산기 열기](https://doricalc-holo.live/)

## 주요 기능

- 라이브 편성 및 점수 분석
- 카드와 보드 정보 확인
- 악곡 및 채보 데이터 조회
- 편성 조합 최적화와 이벤트 효율 비교

## 데이터와 개인정보

서비스는 정적 GitHub Pages로 제공되며, 계산과 사용자 데이터 저장은 브라우저에서 처리됩니다. 공개 가능 시각과 승인 데이터 버전 검증을 통과한 데이터만 배포합니다.

## 저장소 안내

이 저장소에는 GitHub Pages 배포용으로 자동 생성된 파일만 있습니다. 원본 코드와 개발 데이터는 별도의 비공개 저장소에서 관리하며, 이 저장소의 파일은 자동 배포 과정에서 갱신될 수 있습니다.
